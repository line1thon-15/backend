# ADR-0009: 연습 출제 — 정상 상황 슬롯 방식 30%, 변형은 백엔드가 결정

> 상태: 제안 (docs/Architecture.md 초안과 함께 사용자 승인 대기). 승인된 ADR은 수정하지 않는다 — 뒤집으려면 새 ADR로 대체.
> 날짜: 2026-11-06

## 맥락

- F-17 ①: "Given 적응 조정 전 상태 When 연습 출제 Then 정상 상황 비율이 30%로 출제된다(산정 방식은 설계에서 확정)." 적응형 규칙은 PRD OQ 14(보류).
- F-12: 같은 목표 단서로 2회 출제 시 "말투·플랫폼·인물 중 1개 이상이 다르다". F-13 ③ "다시 도전"은 같은 단서의 새 변형.
- F-14 ②: 고등학생이 아니면 고수익 알바 미출제. F-08: 자주 쓰는 앱 → 플랫폼.
- 시연 흐름(PRD.md:40)은 "사기 연습 2회(같은 단서, 다른 모습)" — 시연 초반에 정상 상황이 나오면 흐름이 깨진다.
- 테스트(AGENTS.md 검증 루프)가 가능하려면 규칙이 결정적이어야 한다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| A. 슬롯 방식 — 아이별 새 출제 순번 `draw_index`(1부터, 다시 도전 제외)가 `mod 10 ∈ {4,7,0}`이면 정상 | 10회마다 정확히 30%, 결정적이라 단위 테스트 가능, 첫 3회는 위험 상황(시연 안정) | 아이가 순번 패턴을 알아챌 수 있음 — 적응형(OQ 14) 도입 시 교체 |
| B. 매 출제 확률 0.3 | 구현 단순 | 짧은 구간에서 비율 편차 큼, 시연 첫 회가 정상일 수 있음, 테스트는 통계적으로만 가능 |
| C. 직전 10회 중 정상이 3회 미만이면 정상 | 비율 유지 | 첫 출제부터 정상이 연속으로 나옴(0 < 3) — 시연 흐름과 충돌 |
| D. AI가 정상/위험과 변형을 정함 | 다양성 | F-12·F-17을 LLM 없이 검증 불가, 비결정적 |

## 결정

A를 선택한다. 결정적 이유: F-17 ①의 30%를 10회 단위로 정확히 보장하고, 시연 초반 3회가 위험 상황이며, LLM 없이 테스트할 수 있다.

함께 정하는 규칙(Architecture.md "연습 출제 규칙" 표):
- 변형 `{tone, platform, persona}`은 백엔드 domain이 시드 주입 난수로 정해 AI에 넘긴다. 다시 도전은 직전 변형과 1개 이상 다르게.
- 학년 제한은 시나리오 `min_grade`로 후보에서 제외.
- 해당 영역에 정상 상황이 없으면 그 순번은 위험 상황으로 대체(순번 소비).
- 약점 우선·힌트 감소는 구조만 정하고 수치는 설정 상수(PRD OQ 14).

## 결과 (트레이드오프 포함)

- 얻는 것: F-12·F-14 ②·F-17 ①·F-18 ②를 domain 단위 테스트로 검증.
- 감수하는 것: 예측 가능한 순번 패턴. 적응형 규칙(OQ 14)이 정해지면 새 ADR로 대체.
